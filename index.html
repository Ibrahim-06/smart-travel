مشروع تطبيق مصر السياحي الذكي
(Smart Egypt AI Travel App)

تطبيق هجين يجمع خدمات السياحة المصرية كاملة في منصة واحدة مدعومة بالذكاء الاصطناعي (AI Itinerary + RAG Chatbot + Recommendation Engine)، مصممة للتغلب على تشتت السائح بين تطبيقات Booking, Google Maps, TripAdvisor, و ChatGPT.

المشكلة الحالية (Problem Statement)

السائح القادم إلى مصر يعاني من **تشتت شديد** واستخدام عدة تطبيقات منفصلة للرحلة الواحدة:

  • Google Maps لاستكشاف الأماكن والطرق.
  • Booking لحجز الفنادق والإقامة.
  • TripAdvisor للبحث عن المطاعم والمراجعات.
  • تطبيقات الفعاليات المحلية لمعرفة الأحداث الجارية.
  • ChatGPT للأسئلة التاريخية والثقافية العامة.

الحل والهدف (The AI Solution)

تطبيق ذكي متكامل **(All-in-One)** يُلبي جميع احتياجات السائح بضغطة زر واحدة:

  • مولد خطط رحلات أوتوماتيكي بناءً على (الميزانية، الأيام، والاهتمامات).
  • مساعد ذكي (Chatbot) متقن للتاريخ والثقافة المصرية بالـ RAG.
  • سوق للمرشدين السياحيين وحجوزات الفنادق والفعاليات.
  • نظام توصية ذكي يراعي الموقع والميزانية المحددة.

العضو 1: متخصص الأمن السيبراني

تأمين المنظومة، المصادقة، وحماية البيانات والـ Admin Dashboard

التكليفات والمسؤوليات الأساسية:

  • Module 1 (Auth): تطبيق JWT، OAuth2 (Google Login)، وتشفير Bcrypt/Argon2.
  • Rate Limiting & DDoS: إعداد الحماية من هجمات Brute Force و SQLi و XSS.
  • RBAC الصلاحيات: تأمين لوحة التحكم Module 12 وفصل صلاحيات المستخدم/المرشد/الأدمن.
  • Data Privacy: تشفير البيانات الحساسة والحجوزات (Encryption in Transit & Rest).
  • Penetration Testing: إجراء اختبار اختراق شامل وكتابة تقرير التقييم الأمني.
التقنيات الخاصة به: OAuth2, JWT, Helmet, Argon2, OWASP ZAP, Postman Security Tests.
علوم حاسب 1 (CS Lead) AI / ML Engineer

العضو 2: مهندس الذكاء الاصطناعي

بناء عقل التطبيق (RAG Chatbot + Itinerary Generator + Vector DB)

التكليفات والمسؤوليات الأساسية:

  • Module 5 (Itinerary): خوارزمية توليد جدول الرحلات التلقائي بناءً على الميزانية والوقت.
  • Module 9 (AI Bot): بناء Chatbot باستخدام Gemini API وتقنية RAG للإجابة عن التاريخ.
  • Module 10 (Knowledge Base): تحويل التاريخ والثقافة المصرية إلى Vector Database (ChromaDB/PgVector).
  • Recommendation Engine: خوارزمية ترشيح الأماكن والمطاعم حسب اهتمام وخصائص المستخدم.
التقنيات الخاصة به: Python FastAPI, LangChain, Gemini API, ChromaDB / PgVector, Embeddings.
علوم حاسب 2 Backend Lead

العضو 3: مهندس الخلفية وقواعد البيانات

بناء البنية التحتية، تصميم قاعدة البيانات الـ 12 Entities، والـ RESTful APIs

التكليفات والمسؤوليات الأساسية:

  • Database Architecture: بناء قاعدة بيانات PostgreSQL تستوعب 12 Entity والعلاقات بينها.
  • Module 4 & 10 APIs: بناء APIs الأماكن، المتاحف، الأهرامات، والمعلومات التاريخية.
  • Module 12 Backend: APIs لوحة التحكم (CRUD Operations) لإضافة وتعديل الأماكن والأحداث.
  • DevOps & Server: حزم التطبيق بـ Docker ورفعه على خوادم سحابية (Render/AWS).
التقنيات الخاصة به: PostgreSQL, Node.js Express / Python FastAPI, Prisma ORM, Docker.
علوم حاسب 3 Mobile / Frontend

العضو 4: مهندس الواجهات والتطبيق

بناء واجهات التطبيق وتجربة المستخدم (Flutter / React Native UI)

التكليفات والمسؤوليات الأساسية:

  • UI Architecture: إعداد هيكل التطبيق وتنسيق إدارة الحالة (State Management - BLoC/Redux).
  • Module 2 & 4 UI: الشاشة الرئيسية، شاشة البحث، الفئات، وعرض تفاصيل المكان والمراجعات.
  • Module 5 & 9 UI: تصميم شاشة إدخال ميزانية الـ AI وشاشة شات البوت التفاعلية.
  • Module 11 UI: شاشة الملف الشخصي، المفضلات، وحفلات وحجوزات السائح.
التقنيات الخاصة به: Flutter / React Native, Figma, Tailwind/Material Design, State Management.

العضو 5: مهندس الخدمات والتكاملات

ربط الخدمات الخارجية (الحجوزات، المرشدين، الخرائط، وبوابة الدفع)

التكليفات والمسؤوليات الأساسية:

  • Module 3 & 6 (Bookings/Events): منطق حجوزات الفنادق والتذاكر والفعاليات الجارية.
  • Module 8 (Tour Guides): بناء سوق المرشدين السياحيين (الملفات، اللغات، والتقييم).

وحدات التطبيق (12 Modules) وجداول قاعدة البيانات (12 ERD Entities)

التفاصيل الهيكلية والربط بين مكونات البروجكت المختلفة.

الـ 12 Module الموجودة في التطبيق:

1. Authentication Cyber / CS 2

Login, Signup, Forget Password, Google OAuth Login, Email Verification, JWT Token Refresh.

2. Home Dashboard CS 3

شريط البحث، الفئات، التوصيات المخصصة، حالة الطقس الحالية، والأماكن المميزة بالقرب من السائح.

3. Booking Module CS 4

حجوزات الفنادق، الرحلات السياحية، وتذاكر دخول الأماكن والمتاحف بالتكامل مع الدفع الإلكتروني.

4. Places Explorer CS 2 / CS 3

استعراض المتاحف، المعابد، الشواطئ، الحدائق، والمناطق التاريخية مع الصور، التقييم، وساعات العمل وخريطة الموقع.

5. Smart Itinerary Generator ★ CS 1 (AI)

إدخال الميزانية + الأيام + الاهتمامات ⬅️ توليد خطة رحلة يومية متكاملة ومنطقية أوتوماتيكياً بواسطة الذكاء الاصطناعي.

6. Events Module CS 4

عرض الحفلات، المهرجانات، المعارض المتوفرة اليوم وفي هذا الأسبوع مع إمكانية حجز التذاكر.

7. Food Discovery CS 4

اقتراح المطاعم، الكافيهات، الأكل الشعبي، وأكل الشارع المصري بناءً على موقع السائح الحالي.

8. Tour Guide Marketplace CS 4

عرض المرشدين السياحيين المرخصين، التقييم، اللغات المتقنة، السعر، والتواصل المباشر والحجز.

9. AI Assistant Chatbot CS 1 (AI)

مساعد سياحي ذكي يجيب عن أسئلة السائح حول الآثار، تاريخ معبد الكرنك، أفضل وقت للزيارة، والأنشطة العائلية.

10. Egypt Knowledge Library CS 2 / CS 1

مكتبة ثقافة وحضارة الفراعنة، العادات المصرية، العبارات اللغوية الشائعة، والنصائح الثقافية للزوار.

11. User Profile CS 3

تعديل البيانات الشخصية، عرض الأماكن المفضلة Saved Favorites، متابعة الحجوزات، والخطط السابقة.

12. Admin Dashboard Cyber / CS 2

لوحة تحكم مشفّرة للإدارة: إضافة وتعديل وحذف الأماكن، الفعاليات، قبول المرشدين، ومتابعة الإحصائيات.

قاعدة البيانات الشاملة (12 ERD Entities Map) Relational Schema (PostgreSQL)

1. Users

id, name, email, password_hash, role (tourist/guide/admin)

2. Attractions

id, name, category, location, rating, opening_hours, images

3. Hotels

id, name, city, stars, price_per_night, amenities, map_url

4. Restaurants

id, name, cuisine_type, price_range, location, rating

5. Events

id, title, date, venue, ticket_price, description, capacity

6. Bookings

id, user_id, booking_type, target_id, amount, status, date

7. Reviews

id, user_id, target_type, rating, comment, created_at

8. Favorites

id, user_id, attraction_id, hotel_id, saved_at

9. Tour Guides

id, user_id, languages, price_per_day, verified, bio

10. User Preferences

id, user_id, budget_range, favorite_activities, travel_style

11. Itineraries

id, user_id, days_count, total_budget, generated_json

12. AI Conversations

id, user_id, prompt_text, response_text, vector_references

التقنيات والأدوات الواجب معرفتها بالتفصيل

الأدوات التقنية والمكتبات الموصى بها لكل دور في الفريق لبدء العمل بسلاسة.

1. تقنيات التطبيق والواجهات (Frontend Lead - CS 3)

  • Flutter (Dart) أو React Native: لتطوير تطبيق متوافق مع Android و iOS بكود برمجي واحد.
  • إدارة الحالة State Management: استخدام BLoC / Provider في Flutter أو Redux Toolkit في React Native.
  • Figma: لتصميم وشرح نماذج الشاشات والـ UI Flow قبل تكويدها.

2. تقنيات الذكاء الاصطناعي (AI Lead - CS 1)

  • Gemini API / OpenAI API: للتعامل مع النماذج اللغوية الضخمة وتوليد الجداول والردود.
  • LangChain / LlamaIndex: لإدارة سلسلة الـ Prompts وربط الـ Chatbot ببيانات خارجيه.
  • ChromaDB / PgVector: قواعد بيانات متجهية لتخزين تاريخ مصر وإجراء بحث تشابهي (Vector Search).

3. تقنيات الخلفية والبيانات (Backend Lead - CS 2)

  • Python FastAPI / Node.js (Express): لإغلاق الـ Endpoints بسرعة وسهولة دمج الـ AI.
  • PostgreSQL + Prisma / SQLAlchemy ORM: للتعامل مع قاعدة البيانات الترابطية وسهولة الـ Migrations.
  • Docker & Cloud Hosting: حزم التطبيق ونشره على Render أو DigitalOcean أو AWS.

4. تقنيات أمن المعلومات (Cybersecurity Lead)

  • JWT & OAuth 2.0: لتأمين جلسات المستخدمين وتفعيل تسجيل الدخول بـ Google.
  • Argon2 / Bcrypt & Encryption: لتشفير كلمات المرور والبيانات في التخزين والنقل.
  • OWASP ZAP / Burp Suite: لفحص ثغرات الـ API واختبار الاختراق قبل الإطلاق.
