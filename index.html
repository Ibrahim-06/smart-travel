منظومة متعددة المنصات (Mobile App + Web Portal)

منظومة مصر السياحية الذكية الموحدة
(Unified Mobile & Web Cross-Platform)

نظام متكامل يتكون من **تطبيق موبايل (Mobile App)** للسياح والمرشدين أثناء التنقل، و **موقع إلكتروني (Web Portal)** للحجوزات ولوحة الإدارة Admin Dashboard، كلاهما متصلان بـ **خلفية برمجية موحدة (Unified Central Backend)** وقاعدة بيانات واحدة (Shared PostgreSQL + PgVector).

معمارية الربط الموحدة (Cross-Platform Architecture)

1 Shared Database + 1 Central API Backend

تطبيق الموبايل (Mobile App)

Flutter / React Native

مخصص للسياح والمرشدين في الشارع: تحديد الموقع الجغرافي GPS، الدردشة الصوتية مع الـ AI، التنبيهات المباشرة، وحفظ المفضلات بدون إنترنت.

موقع الويب (Web Portal)

React.js / Next.js / Flutter Web

مخصص للتخطيط المسبق، استعراض المتاحف على الشاشات الكبيرة، لوحة تحكم المرشدين، ولوحة الإدارة الشاملة (Admin Dashboard).

الخلفية وقاعدة البيانات الموحدة

FastAPI + PostgreSQL + PgVector

خادم مركزي يوفر RESTful APIs موحدة ومحركات الذكاء الاصطناعي (RAG + Itinerary) متصلة بـ Single PostgreSQL Database لجميع المنصات.

الربط والتزامن اللحظي (Real-Time Synchronization): أي حجز أو خطة رحلة يتم إنشاؤها عبر **موقع الويب** تظهر فوراً في **تطبيق الموبايل** الخاص بالحساب، والعكس صحيح، مع استخدام JWT Token موحد لتسجيل الدخول عبر المنصتين.

المشكلة الحالية (Problem Statement)

السائح القادم إلى مصر يعاني من **تشتت شديد** واستخدام عدة تطبيقات منفصلة للرحلة الواحدة:

  • Google Maps لاستكشاف الأماكن والطرق.
  • Booking لحجز الفنادق والإقامة.
  • TripAdvisor للبحث عن المطاعم والمراجعات.
  • تطبيقات الفعاليات المحلية لمعرفة الأحداث الجارية.
  • ChatGPT للأسئلة التاريخية والثقافية العامة.

الحل والهدف (The AI Solution)

تطبيق ذكي متكامل **(All-in-One)** يُلبي جميع احتياجات السائح بضغطة زر واحدة:

  • مولد خطط رحلات أوتوماتيكي بناءً على (الميزانية، الأيام، والاهتمامات).
  • مساعد ذكي (Chatbot) متقن للتاريخ والثقافة المصرية بالـ RAG.
  • سوق للمرشدين السياحيين وحجوزات الفنادق والفعاليات.
  • نظام توصية ذكي يراعي الموقع والميزانية المحددة.

العضو 1: متخصص الأمن السيبراني

تأمين المنظومة الموحدة (Mobile Security + Web Auth + Admin Access)

التكليفات والمسؤوليات الأساسية:

  • Cross-Platform Auth (Module 1): تطبيق JWT Tokens موحد للموبايل والويب، مع تخزين آمن (Secure Storage على الموبايل و httpOnly Cookies على الويب).
  • CORS & Web Security: ضبط سياسات CORS للـ Backend لمنع الطلبات غير المصرح بها من مواقع أخرى، وتأمين الـ REST Endpoints.
  • RBAC الصلاحيات: حماية الـ Admin Web Dashboard وفصل صلاحيات السائح، المرشد، والمدير.
  • Penetration Testing: اختبار اختراق تطبيق الموبايل (APK) وموقع الويب (Web App) والتأكد من سلامة المعاملات.
التقنيات: OAuth2, JWT, Flutter Secure Storage, CORS Policies, OWASP ZAP, Helmet.js.
علوم حاسب 1 (CS Lead) AI / ML Engineer

العضو 2: مهندس الذكاء الاصطناعي

بناء خدمات الـ AI الموحدة المصممة للاستدعاء السريع من الويب والموبايل

التكليفات والمسؤوليات الأساسية:

  • Module 5 (Itinerary Engine): خوارزمية توليد جدول الرحلات وإرجاع النتيجة بصيغة JSON خفيفة تتوافق مع الويب والموبايل.
  • Module 9 (AI Chatbot): بناء الـ Chatbot بـ RAG والـ Streaming Response لإعطاء استجابة سريعة على الموبايل والويب.
  • Vector Database: ربط PgVector مع قاعدة البيانات الرئيسية وتحديث سياق التاريخ والثقافة بشكل مركزي.
التقنيات: Python FastAPI Microservice, LangChain, Gemini API, PgVector, Server-Sent Events (SSE).
علوم حاسب 2 Backend & Shared DB

العضو 3: مهندس الخادم وقواعد البيانات الموحدة

بناء الـ Unified Central REST APIs وقاعدة البيانات الـ 12 Entity المشتركة

التكليفات والمسؤوليات الأساسية:

  • Central Database: بناء قاعدة بيانات PostgreSQL الموحدة وتحديث البيانات لحظياً بين الموبايل والويب.
  • Unified RESTful APIs: كتابة APIs القياسية لاستعلام الأماكن، الفنادق، والحجوزات لتعمل بسلاسة مع الموبايل والويب.
  • Admin Dashboard APIs: APIs لوحة التحكم بالويب (CRUD Operations) لإدارة كل النظام من الويب.
التقنيات: PostgreSQL, Node.js Express / FastAPI, Prisma ORM, Swagger API Docs, Docker.
علوم حاسب 3 Mobile & Web Frontend

وحدات التطبيق (12 Modules) وجداول قاعدة البيانات (12 ERD Entities)

التفاصيل الهيكلية والربط بين مكونات البروجكت المختلفة.

الـ 12 Module الموجودة في التطبيق:

1. Authentication Cyber / CS 2

Login, Signup, Forget Password, Google OAuth Login, Email Verification, JWT Token Refresh.

2. Home Dashboard CS 3

شريط البحث، الفئات، التوصيات المخصصة، حالة الطقس الحالية، والأماكن المميزة بالقرب من السائح.

3. Booking Module CS 4

حجوزات الفنادق، الرحلات السياحية، وتذاكر دخول الأماكن والمتاحف بالتكامل مع الدفع الإلكتروني.

4. Places Explorer CS 2 / CS 3

استعراض المتاحف، المعابد، الشواطئ، الحدائق، والمناطق التاريخية مع الصور، التقييم، وساعات العمل وخريطة الموقع.

5. Smart Itinerary Generator ★ CS 1 (AI)

إدخال الميزانية + الأيام + الاهتمامات ⬅️ توليد خطة رحلة يومية متكاملة ومنطقية أوتوماتيكياً بواسطة الذكاء الاصطناعي.

6. Events Module CS 4

عرض الحفلات، المهرجانات، المعارض المتوفرة اليوم وفي هذا الأسبوع مع إمكانية حجز التذاكر.

7. Food Discovery CS 4

اقتراح المطاعم، الكافيهات، الأكل الشعبي، وأكل الشارع المصري بناءً على موقع السائح الحالي.

8. Tour Guide Marketplace CS 4

عرض المرشدين السياحيين المرخصين، التقييم، اللغات المتقنة، السعر، والتواصل المباشر والحجز.

9. AI Assistant Chatbot CS 1 (AI)

مساعد سياحي ذكي يجيب عن أسئلة السائح حول الآثار، تاريخ معبد الكرنك، أفضل وقت للزيارة، والأنشطة العائلية.

10. Egypt Knowledge Library CS 2 / CS 1

مكتبة ثقافة وحضارة الفراعنة، العادات المصرية، العبارات اللغوية الشائعة، والنصائح الثقافية للزوار.

11. User Profile CS 3

تعديل البيانات الشخصية، عرض الأماكن المفضلة Saved Favorites، متابعة الحجوزات، والخطط السابقة.

12. Admin Dashboard Cyber / CS 2

لوحة تحكم مشفّرة للإدارة: إضافة وتعديل وحذف الأماكن، الفعاليات، قبول المرشدين، ومتابعة الإحصائيات.

قاعدة البيانات الشاملة (12 ERD Entities Map) Relational Schema (PostgreSQL)

1. Users

id, name, email, password_hash, role (tourist/guide/admin)

2. Attractions

id, name, category, location, rating, opening_hours, images

3. Hotels

id, name, city, stars, price_per_night, amenities, map_url

4. Restaurants

id, name, cuisine_type, price_range, location, rating

5. Events

id, title, date, venue, ticket_price, description, capacity

6. Bookings

id, user_id, booking_type, target_id, amount, status, date

7. Reviews

id, user_id, target_type, rating, comment, created_at

8. Favorites

id, user_id, attraction_id, hotel_id, saved_at

9. Tour Guides

id, user_id, languages, price_per_day, verified, bio

10. User Preferences

id, user_id, budget_range, favorite_activities, travel_style

11. Itineraries

id, user_id, days_count, total_budget, generated_json

12. AI Conversations

id, user_id, prompt_text, response_text, vector_references

التقنيات والأدوات الموصى بها للـ Mobile & Web Ecosystem

الأدوات البرمجية للربط بين تطبيق الموبايل، موقع الويب، وقاعدة البيانات الموحدة.

1. تقنيات الموبايل والويب (Frontend & Mobile CS 3)

  • Flutter (Dart) أو React + React Native: يتيح استخدام Flutter لتطوير الموبايل (iOS/Android) وكذلك موقع الويب بكود متشارك بنسبة كبيرة.
  • State Management (BLoC / Provider / Redux): لمزامنة بيانات الحساب، الخطة، والحجوزات بين الموبايل والويب.
  • Tailwind CSS + Figma: لتصاميم تجاوبية سريعة على الويب والموبايل.

2. تقنيات الذكاء الاصطناعي (AI Lead - CS 1)

  • Gemini API / OpenAI API: معالجة استفسارات السائحين على المنصتين.
  • LangChain / LlamaIndex & Streaming: توفير بث الإجابات اللحظي (SSE) لـ AI Assistant على الويب والموبايل.
  • PgVector Extension: تخزين الـ Embeddings مباشرة في قاعدة بيانات PostgreSQL الموحدة.

3. الخادم وقاعدة البيانات الموحدة (Backend Lead - CS 2)

  • Python FastAPI / Node.js Express: خادم مركزي يخدم تطبيق الموبايل وموقع الويب كـ Central RESTful API.
  • PostgreSQL + Prisma ORM: قاعدة البيانات الرئيسية الوحيدة (Shared Database) بـ 12 Entity.
  • Cloud Hosting (Render / AWS / Supabase): رفع الخادم ليكون متاحاً دائماً للموبايل والويب.

4. أمن المعلومات للموبايل والويب (Cybersecurity)

  • JWT & OAuth 2.0 Flow: نظام مصادقة موحد يتيح الدخول بـ Google أو البريد الإلكتروني عبر الموبايل والويب.
  • Secure Token Storage & CORS: تخزين الـ Token بـ KeyStore/Keychain في الموبايل و HTTP-Only Cookies بالويب.
  • Penetration Testing Tools: استخدام OWASP ZAP لفحص الـ APIs و Burp Suite لفحص استجابة المنصتين.
